# AI 视频监控系统 Web UI 设计文档

**日期:** 2026-04-11
**主题:** 基于 Gradio 的双页 Web 监控界面

## 需求

构建一个 Gradio Web UI，将现有 AI 视频监控能力从终端迁移到浏览器界面。

## 架构

### 整体设计

```
启动阶段（一次性）                    运行阶段
┌─────────────────────┐              ┌──────────────────────┐
│ 加载所有检测模型      │              │ 选择文件/摄像头        │
│  human_model        │              │ 实时检测 + 渲染        │
│  cigarette_model    │              │ 统计计数 + 日志记录     │
│  mask_model         │              │ 页面一/页面二切换      │
│  fire_model         │              └──────────────────────┘
│  pose_model         │
└─────────────────────┘
```

### 页面分工

**页面一：实时监控（主页）**
- 顶部 5 个统计卡片（火、烟、抽烟、未戴口罩、睡岗）
- 左侧：实时视频画面 + 播放控制（文件选择、播放/暂停）
- 右侧：精简日志流（最近 5-10 条异常记录）
- 支持摄像头实时接入

**页面二：后台管理**
- 分类统计汇总卡片
- 完整日志表格（时间/类型/置信度/截图）
- 日志筛选、搜索
- 模型置信度阈值调整

## 技术选型

- **框架:** Gradio（单文件、Python 集成、自带 Web 服务）
- **视频渲染:** Gradio Image 组件 + OpenCV 帧传输
- **统计显示:** Gradio HTML/Markdown 组件渲染彩色卡片
- **日志存储:** 内存列表（会话级）

## 数据流

```
检测线程 (已有) ──→ 共享状态 (已有) ──→ Gradio 读取 ──→ 页面渲染
                      │
                      └──→ 异常日志记录 ──→ 页面二日志表格
```

## 关键设计决策

1. **模型预加载** — 应用启动时加载所有模型，切换文件/摄像头不需要重新加载
2. **文件可反复选择** — 检测完成后可以选择新文件，重新播放
3. **摄像头接入** — 除了文件，还能选择系统摄像头实时检测
4. **日志去重** — 同一类异常 5 秒内只记录一条，避免刷屏
5. **浅色主题** — Gradio 内置 soft 主题 + 自定义 CSS 统计卡片
